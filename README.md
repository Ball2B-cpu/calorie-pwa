# จดแคล (calorie-pwa)

เว็บแอพ (PWA) จดอาหาร/แคลอรีรายวัน ใช้บนมือถือ ติดตั้งเป็นไอคอนได้ **ทำงานได้แม้ไม่มีเน็ต**

## repo นี้มีแต่โค้ด
- **ไม่มีข้อมูลสุขภาพ** — บันทึกทั้งหมดอยู่ใน IndexedDB ของเครื่องผู้ใช้ และสำเนาอยู่ใน repo ส่วนตัวของผู้ใช้เอง
- **ไม่มี API key / token** — ผู้ใช้กรอกเองในหน้าตั้งค่าของแอพ เก็บไว้ในเครื่องตัวเองเท่านั้น
- `fixtures/`, `days/`, `photos/`, `profile.json` ถูก gitignore ไว้

## ใช้งาน
เปิดหน้าเว็บ → Add to Home Screen → เปิดจากไอคอน (ไม่ใช่แท็บเบราว์เซอร์ เพราะเป็นที่เก็บข้อมูลคนละที่)

## โครงไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้า + `<head>` PWA + error boundary (inline ต้องทำงานแม้โมดูลโหลดไม่ได้) |
| `css/app.css` | ตัวแปรสี (สว่าง/มืด) + layout |
| `js/app.js` | bootstrap, ลงทะเบียน service worker, สลับแท็บ |
| `js/db.js` | IndexedDB (days/photos/outbox/meta) + `mergeDay()` + คิวส่ง |
| `js/ui.js` | แดชบอร์ดรายวัน/ปฏิทินเดือน/ฟอร์มจด/รูป/หน้าตั้งค่า |
| `js/net.js` | เรียก AI ประเมินแคล + ซิงก์ขึ้น GitHub |
| `data/foods.json` | คลังอาหารสำหรับเติมคำอัตโนมัติ (ค่าโภชนาการจากฉลาก ไม่ใช่ข้อมูลส่วนตัว) |
| `sw.js` | service worker (offline) — **แก้ไฟล์ใดก็ต้อง bump `VERSION`** |
| `tests.html` | ชุดทดสอบ `mergeDay` / outbox / export-import (เปิดในเบราว์เซอร์) |

## กฎเหล็กเวลาแก้โค้ด
1. แก้ไฟล์ที่อยู่ใน `SHELL` ของ `sw.js` → **ต้อง bump `VERSION`** ไม่งั้นมือถือเห็นของเก่าจากแคช
2. ห้ามเขียน key/token ลงไฟล์ใด ๆ ในนี้
3. ห้ามเพิ่ม dependency/CDN (ยกเว้น Google Fonts ที่ใช้อยู่)
4. อ่าน `SCHEMA.md` ก่อนแตะโครงสร้างข้อมูล — เป็นสัญญาที่ทั้งแอพและสคริปต์ฝั่งคอมใช้ร่วมกัน
